# AI STUDIO 拡張機能

Game Canvas のワークスペースから、別タブで文章チャット・画像生成・画像編集を使えます。

## 使い始める

ワークスペースの「拡張機能」で AI STUDIO を追加し、「AI STUDIOを開く」を選びます。設定だけを開く場合は `/w/<slug>/extensions` を使えます。追加・停止はワークスペースのオーナーが行います。

元の水無墓村と、そのオーナーが管理するワークスペースで利用できます。名前を同じにするだけでは利用できません。メンバー認証は各リクエストで検証し、ワークスペースごとに一時結果とGPUの利用者識別を分離します。停止・退会・所有権の変更後はアクセスを拒否します。

モデルは必要に応じて自動起動します。文章・画像生成・画像編集は共通のGPU順番待ちを使います。PCがオフラインの場合は接続待ちを表示し、自動再接続と手動の再試行に対応します。利用端末のMeshnet参加は不要です。

## 画像編集

「画像編集」でPNG・JPEG・WebPを選び、変更したい内容を入力します。元画像は自分の順番が来てから一時メモリへ送信します。元画像を選ばない場合は文章から画像を生成します。

結果は利用端末で復号し、2分間表示します。「画像と一時鍵を閉じる」で表示と端末の一時鍵を手動で破棄できます。処理中に鍵を閉じた場合、その鍵を使う結果は表示できなくなります。

## データの扱い

- 通信内容を認証付きで暗号化し、中継の一時データは取得後または期限切れ時に消去します。
- 会話・画像・復号鍵をアプリがブラウザーの永続ストレージへ自動保存することはありません。
- PC側の画像結果は暗号化してRAMだけで保持します。未受信の最大保管は10分、受信後は2分です。
- HTTPキャッシュを禁止し、ページ終了時は会話表示・鍵・画像表示を解放します。
- OSのスワップ、ブラウザー内部のコピー、GPUメモリまで完全に残らないことを保証するものではありません。

## 検証

`node --test tests/lllm-relay.test.mjs` で認証、CSRF、暗号化、中継、ワークスペース分離、停止・退会時の拒否、再接続を検証できます。実機の画像テストはユーザー画像を使用せず、専用の合成図形で行います。
